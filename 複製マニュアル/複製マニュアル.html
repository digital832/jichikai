自治会システム 複製・導入マニュアル

新しい自治会にLINE回覧板システムを導入するときの手順書です。この仕組みは「1自治会 = 1フォルダ（1セット）」で運用します。既存の自治会のコードを触らず、フォルダをまるごと複製して新しい独立した1セットを作ってください。この画面の入力欄はこのパソコンのブラウザ内だけに保存され、外部には送信されません。

1LINE公式アカウントを用意する

この自治会専用のLINE公式アカウントを作成し、Messaging APIのチャネルアクセストークンを発行します。班によって複数のLINE公式アカウントを使い分ける場合は、班の数だけこの手順を繰り返してください。審査に数日かかることがあるため、最初に着手しておくのがおすすめです。

↗ LINE公式アカウントを作成 ↗ LINE Developersでトークン発行

LINE Developersコンソールで、作成した公式アカウントに対応するチャネルを開き、「Messaging API設定」タブの一番下にある「チャネルアクセストークン（長期）」を発行してください。

このトークンは、名簿スプレッドシートの「名簿」タブ・F列「アクセストークン」に、対象になる会員の行すべてへコピペします（1人ずつ手作業になります）。班ごとに公式アカウントを分ける場合は、該当する班の行にそれぞれのトークンを入れてください。

🚀班別LINEリスト準備ツール

班によって複数のLINE公式アカウントを使い分ける場合に使う、別のツールです。テンプレートフォルダのこの自治会用への複製から、班ごとのスプレッドシート複製・チャンネルアクセストークンの貼り付けまで、ボタン操作だけで行えます（上の①・下の②で複数の公式アカウントを使う場合はこちらを使ってください）。

↗ 班別LINEリスト準備ツールを開く

2LINEの友だちリストを名簿に取り込む

名簿スプレッドシートには、LINEの友だちリストを名簿タブに自動で取り込むためのスクリプト（GAS）が用意されています。スプレッドシートのメニュー「拡張機能」→「Apps Script」から、取り込み用のスクリプトを実行してください。手順やボタンの場所が分からない場合は、テンプレート作成担当（阿部さん）に確認してください。ここはこのマニュアルの対象外（スプレッドシート側の作業）です。

管理用IDは、フォルダ名やGitHubリポジトリ名に使う半角英数字です（ひらがな・漢字は使えません）。入力すると自動でこのブラウザに保存され、画面を閉じても入力内容が残ります。

🔧初回セットアップ（最初の1回だけ）

下のコマンドを1回だけPowerShellにコピー＆ペーストして実行しておくと、次のStep③でボタンを押すだけでPowerShellが自動的に開いてフォルダ複製が実行されるようになります（このパソコン限定の設定です）。実行時にWindowsから「このアプリを開きますか？」のような確認が出ることがありますが、許可してください。スキップしても、Step③の「コマンドをコピー」から今まで通り手動で複製できます。


      
    

  


  
  

    
3プロジェクトフォルダを複製する

    
下にフォルダ名を入力し、「自動で複製を実行」ボタンを押す（上のセットアップ済みの場合）か、コマンドをコピーしてPowerShellに貼り付けて実行すると、「自治会フォルダ」の中に「自治会tmp_制作用」フォルダがまるごと複製され、GitHubに繋がった「.git」隠しフォルダも自動で削除されます（これを消さずに進めると、新しい自治会の変更が誤って元のリポジトリに送られてしまう危険があるため）。
・今動いている自治会のシステムには一切触れません。安心して実行してください。

5環境変数（.env）の内容を作る

    
ここまでで集めた情報から、Renderに設定する環境変数をまとめて作ります。秘密鍵（GOOGLE_SA_PRIVATE_KEY）は全自治会共通のものを使い回すので、今動いている自治会のシステムの.envファイル、または阿部さんが管理している保管場所から同じ内容をコピーしてください。

    

      
      
      
この内容はこのブラウザにのみ保存されます。人に渡すときは画面共有やチャットへの直接貼り付けを避け、口頭やパスワード管理ツールなど安全な方法で伝えてください。

    

    

      
      
    

    
下に、ここまでに入力した自治会名と、このステップで入力した内容から自動生成した.envの中身が表示されます。空欄の項目は手順を戻って埋めてください。

    

      

      
    

    
スプレッドシートのタブ名（名簿・Events・グループマスタ・防災設定など）をテンプレートから変更していない場合、上記以外の環境変数は設定不要です（プログラム側に既定値が入っています）。

    

      
      
    

  


  
  

    
6Renderにデプロイする

    
1.「New +」→「Web Service」を選択
2.「Build and deploy from a Git repository」で、④で作成したGitHubリポジトリを選択（一覧に出ない場合は「Configure GitHub App」でRenderにリポジトリへのアクセスを許可）
3. Environmentは「Docker」が自動選択されます（フォルダにDockerfileが入っているため）
4.「Environment Variables」の「Add from .env」に、⑤でコピーした内容をそのまま貼り付け
5.「Create Web Service」を押してデプロイ開始（数分かかります）

    

      ↗ Renderダッシュボードを開く
